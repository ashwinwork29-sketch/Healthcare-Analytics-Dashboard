# 🏥 Healthcare Analytics Dashboard

## 📊 Project Overview
This project is a Power BI dashboard designed to analyze hospital data and provide insights into patient trends, department performance, and billing patterns.

## 🛠 Tools Used
- Microsoft Power BI
- Python (Pandas)
- Excel / CSV

## 📈 Features
- Patient admission analysis
- Department-wise performance
- Revenue and billing insights
- Age group and gender analysis
- Disease trend analysis

## 📸 Dashboard Preview
![Dashboard](images/https://github.com/ashwinwork29-sketch/Healthcare-Analytics-Dashboard/blob/main/Healthcare%20Data%20Analytics.png)

## 🧠 Key Insights
- Senior patients have higher average billing
- Certain departments generate more revenue
- Disease trends help in healthcare planning
- Patient distribution varies across age groups

## 📁 Files Included
- Power BI Dashboard (.pbix)
- Dataset (.csv)
- Python data cleaning script
- Dashboard screenshot

## 🎯 Conclusion
This dashboard helps in data-driven decision-making for hospital management by converting raw data into meaningful insights.
